# Gyeonggi Business Pipeline

Data pipeline for monthly snapshots of the Korean small-business registry (data.go.kr, Gyeonggi):
raw layer -> SQLite staging -> 5 data-quality checks (pytest) -> BI dashboard.

Data is not included; download it from data.go.kr.
